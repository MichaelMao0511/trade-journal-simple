# 交易记录登记助手（simple）

一个极简的 A 股交易记录登记 skill：把每笔成交按固定字段写入 `交易记录.xlsx`，首次使用时自动生成 Excel 空模板和 `使用说明.md`。

> 简单版定位：只做交易登记，不做统计、盈亏分析或复盘。需要统计复盘时，直接向你的 agent 提问即可。

公众号：金方土2025

## 一键安装

把下面这句话发给你的 agent，让它帮你安装：

```
请帮我把这个 GitHub 仓库安装为本地 skill：https://github.com/MichaelMao0511/trade-journal-simple
```

agent 会自动把仓库 clone 到 `~/.workbuddy/skills/` 并验证 `SKILL.md` 存在。

## 使用方式

安装完成后，对你的 agent 说类似的话即可触发：

- 「帮我记录一笔交易」
- 「登记一笔成交」
- 「建仓了 XX，帮我记一下」
- 「我今天减仓了 XX」

首次使用时，agent 会在你的项目目录生成 `交易记录.xlsx` 和 `使用说明.md`，并提示你说明文档的位置。

> 注意：安装本身**不会**生成 Excel，只是把 skill 放进技能目录。需要在你想放交易记录的项目里说「帮我记录一笔交易」，首次触发时才会生成 `交易记录.xlsx` 和 `使用说明.md`。

## 字段一览

| 字段 | 怎么填 |
|---|---|
| 交易编号 | 同一轮建仓、加仓、减仓、清仓用同一个编号 |
| 日期 | 实际成交日 |
| 标的 | 股票、ETF、基金等 |
| 操作 | 建仓、加仓、减仓、清仓 |
| 成交价 | 实际价格 |
| 数量/金额 | 二选一即可 |
| 仓位比例 | 占账户资金多少 |
| 交易理由 | 一句话写清楚为什么做 |
| 止损价/风险控制 | 怎样说明原判断错了（价格、基本面） |
| 清仓复盘 | 卖出原因、是否按计划、下一次注意什么 |

## 个性化

字段和规则都是默认模板，建议按你自己的交易习惯调整；不会优化就直接把你的需求告诉你的 agent，让它帮你改。
