# 交易记录使用说明

> 本说明由 skill 首次运行时自动生成。公众号：金方土2025

## 这是什么

`交易记录.xlsx` 用于记录你的每一笔股票交易，帮助你复盘每一次买入卖出的决策是否合理。

## 字段填写规范

| 字段 | 怎么填 |
|---|---|
| 交易编号 | 同一轮建仓、加仓、减仓、清仓用同一个编号 |
| 日期 | 实际成交日 |
| 标的 | 股票、ETF、基金等 |
| 操作 | 建仓、加仓、减仓、清仓 |
| 成交价 | 实际价格 |
| 数量/金额 | 二选一即可 |
| 仓位比例 | 占账户资金多少 |
| 交易理由 | 一句话写清楚为什么做 |
| 止损价/风险控制 | 怎样说明原判断错了（价格、基本面） |
| 清仓复盘 | 卖出原因、是否按计划、下一次注意什么 |

## 操作类型说明

- **建仓**：首次买入一只股票，创建新的交易编号。
- **加仓**：已持有股票继续买入，沿用同一交易编号。
- **减仓**：已持有股票部分卖出，沿用同一交易编号。
- **清仓**：全部卖出，记录复盘。

## 填写约定

- 建仓必须填写「交易理由」和「止损价/风险控制」。
- 截图中无法确认的信息，不要猜测，标记为「待确认」。
- 历史记录只新增，不覆盖、不修改。
